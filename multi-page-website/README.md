# Multi-Page Website (Portfólio em HTML Puro)

Repositório técnico dedicado ao segundo desafio do módulo de HTML do [roadmap.sh](https://roadmap.sh/projects/basic-html-website). O objetivo central deste projeto é aprender a estruturar um site completo de múltiplas páginas utilizando estritamente HTML semântico, sem a aplicação de estilos CSS, preparando uma base sólida e escalável para futuras estilizações.

## 📂 Páginas do Projeto

* **`index.html` (Homepage):** Página inicial contendo a apresentação profissional, seções de projetos em destaque, experiência de trabalho, formação acadêmica e depoimentos, conforme o mockup de referência.
* **`projects.html` (Projects):** Página dedicada à listagem e descrição dos projetos desenvolvidos ao longo da jornada de estudos.
* **`articles.html` (Articles):** Seção destinada a artigos, anotações de aprendizado e reflexões sobre desenvolvimento web e tecnologias.
* **`contact.html` (Contact):** Página de contato equipada com um formulário semântico contendo campos essenciais para nome, e-mail e mensagem.

## 🎯 Requisitos e Boas Práticas Implementadas

* **HTML Semântico:** Utilização correta de elementos estruturais modernos (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<blockquote>`, `<cite>`).
* **Navegação Global:** Barra de navegação integrada de forma consistente em todas as páginas do site, permitindo a transição fluida entre as seções.
* **Otimização para SEO:** Inclusão de meta tags essenciais (`charset`, `viewport`, `title`, `description`) no cabeçalho de cada página.
* **Arquitetura Escalável:** Organização do código de forma limpa e estruturada, facilitando a adição futura de folhas de estilo (CSS) e scripts (JavaScript).
