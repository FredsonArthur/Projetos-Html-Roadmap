# Tooltip Component

Componente de dica flutuante (*tooltip*) interativo desenvolvido como parte dos desafios do roadmap.sh[cite: 2]. O objetivo principal deste projeto foi dominar o posicionamento CSS avançado, efeitos de *hover* e transições suaves puramente em CSS, sem recorrer a JavaScript[cite: 2].

## 🎯 Requisitos e Técnicas Implementadas

* **Posicionamento CSS Absoluto:** Utilização de contentores relativos e absolutos para posicionar a tooltip e a respetiva seta indicadora com precisão geométrica acima do item de navegação[cite: 2].
* **Animações Dinâmicas:** Efeitos de transição suave (*fade-in* e *slide-in*) acionados no estado de *hover*[cite: 2].
* **Puro CSS (Sem JavaScript):** Controlo total da visibilidade, opacidade e transformações utilizando apenas seletores e propriedades nativas do CSS3[cite: 2].
* **Design Minimalista:** Estilização alinhada com o mockup de referência, garantindo uma experiência de navegação limpa e moderna[cite: 2].

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**
* **CSS3** (Posicionamento, Transições, Variáveis CSS, Flexbox)
* **Git & GitHub** para controlo de versões
