# Image Grid

Layout de galeria de imagens e blocos visuais desenvolvido como parte dos desafios do roadmap.sh. O objetivo principal deste projeto foi dominar a técnica de **CSS Grid**, permitindo criar composições assimétricas flexíveis, gerir o espaçamento entre elementos e assegurar um design totalmente responsivo.

## 🎯 Objetivos de Aprendizagem e Técnicas Implementadas

* **Estrutura de Grelha (CSS Grid):** Compreensão dos fundamentos de contentores de grelha, definição de linhas e colunas personalizadas, e posicionamento preciso de itens.
* **Design Responsivo:** Adaptação fluida do layout para diferentes larguras de janela e dispositivos (mobile e desktop).
* **Alinhamento e Espaçamento:** Gestão rigorosa de margens, grelhas e proporções visuais para manter um asseio estético limpo.
* **Layout Assimétrico:** Organização de blocos com dimensões e span diferenciados simulando uma galeria de alta qualidade visual.

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**
* **CSS3** (CSS Grid, Flexbox, Variáveis CSS)
* **Git & GitHub** para controlo de versões
