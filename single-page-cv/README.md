# Projeto: Single-Page CV (Currículo de Página Única)

Este projeto faz parte do módulo de HTML do [roadmap.sh](https://roadmap.sh/projects/single-page-cv) e tem como objetivo principal ensinar a estruturar um currículo profissional utilizando exclusivamente HTML, com foco em boas práticas e semântica.

## 🎯 Requisitos Atendidos

* **HTML Semântico:** Utilização de tags apropriadas (`<header>`, `<main>`, `<section>`, `<article>`, `<address>`) para estruturar seções de dados pessoais, habilidades, educação e histórico de carreira.
* **Meta Tags de SEO:** Inclusão de meta tags essenciais no cabeçalho para otimização em mecanismos de busca.
* **Open Graph (OG):** Configuração de tags OG para garantir um compartilhamento otimizado em redes sociais.
* **Favicon:** Integração de ícone personalizado na aba do navegador.

## 🛠️ Tecnologias Utilizadas

* Apenas **HTML5** puro, preparando a base para futuras estilizações com CSS.
