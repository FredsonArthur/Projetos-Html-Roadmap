# Portfolio CSS (Website Estilizado e Responsivo)

Repositório técnico dedicado ao projeto de estilização com CSS do [roadmap.sh](https://roadmap.sh/projects/portfolio-website). O objetivo principal deste desafio foi transformar a estrutura HTML pura anterior em um site totalmente responsivo, aplicando um design limpo, tipografia consistente e conceitos avançados de layout com CSS[cite: 1].

## 🎯 Requisitos e Técnicas Implementadas

* **Layout Responsivo com Flexbox:** Organização de blocos e seções adaptáveis que mudam de disposição entre dispositivos móveis e telas grandes (desktop)[cite: 1].
* **Media Queries:** Pontos de rutura (*breakpoints*) configurados para ajustar a estrutura conforme o tamanho do ecrã, seguindo os mockups de referência[cite: 1].
* **Modelo de Caixa (Box Model):** Gestão rigorosa de margens, preenchimentos (*padding*), larguras e bordas.
* **Variáveis CSS (Custom Properties):** Utilização de variáveis globais (`:root`) para centralizar a paleta de cores e facilitar a manutenção do design system.
* **Múltiplas Páginas Estilizadas:** Páginas de Início (`index.html`), Projetos (`projects.html`), Artigos (`articles.html`) e Contato (`contact.html`) unificadas pela mesma folha de estilos (`style.css`)[cite: 1].

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**[cite: 1]
* **CSS3** (Flexbox, Variáveis, Media Queries)[cite: 1]
* **Git & GitHub** para versionamento de código
