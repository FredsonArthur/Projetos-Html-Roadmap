# Changelog Component

Componente de registo de alterações (*changelog*) desenvolvido como parte dos desafios do [roadmap.sh](https://roadmap.sh/projects/changelog-component). O foco principal deste projeto é dominar técnicas avançadas de posicionamento em CSS, alinhamento de elementos e criação de uma linha do tempo (*timeline*) responsiva.

## 🎯 Requisitos e Técnicas Implementadas

* **Posicionamento e Layout (`position` e `z-index`):** Utilização de posicionamento relativo e absoluto para construir a linha vertical contínua da linha do tempo.
* **Pseudo-elementos (`::before`):** Empreguei o pseudo-elemento para desenhar dinamicamente a linha central da *timeline* sem poluir a estrutura HTML.
* **Flexbox:** Alinhamento preciso dos itens, datas e conteúdos em ecrãs de diferentes tamanhos.
* **Design Responsivo:** Implementação de *media queries* para adaptar o layout da linha do tempo em dispositivos móveis, reposicionando as datas e os pontos indicadores.

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**
* **CSS3** (Posicionamento, Pseudo-elementos, Flexbox, Variáveis CSS)
* **Git & GitHub** para controlo de versões
