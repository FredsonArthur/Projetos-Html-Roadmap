# Form UI

Componente de formulário acessível desenvolvido como parte dos desafios do roadmap.sh. O objetivo principal deste projeto foi focar em boas práticas de acessibilidade web (WCAG), estruturando campos semânticos, gestão de estados de erro, estados de foco para navegação por teclado e indicadores visuais de progresso.

## 🎯 Requisitos e Técnicas Implementadas

* **Acessibilidade Rigorosa (a11y):** Utilização de elementos `<label>` associados via atributo `for`, atributos ARIA (`aria-required`, `aria-invalid`, `aria-describedby`) e suporte a leitores de ecrã.
* **Estados de Foco e Erro:** Estilização dedicada para campos ativos e mensagens de erro claras associadas a entradas inválidas.
* **Componentes Interativos Estáticos:** Campos de palavra-passe com botões de alternância de visibilidade e suporte a acessibilidade por teclado.
* **Indicadores de Progresso:** Barra circular de conclusão de perfil e lista de verificação detalhada dos requisitos para alcançar 100%.

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**
* **CSS3** (Grid, Flexbox, Variáveis CSS, Posicionamento)
* **Git & GitHub** para controlo de versões
