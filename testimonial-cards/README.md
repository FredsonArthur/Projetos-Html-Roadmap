# Testimonial Cards

Componente de cartões de depoimentos desenvolvido como parte dos desafios do roadmap.sh. O objetivo principal deste projeto foi explorar diferentes técnicas de posicionamento e layout em CSS, estruturando cartões com balões de fala, avaliações por estrelas e carrosséis de avatares.

## 🎯 Requisitos e Técnicas Implementadas

* **Layout com CSS Grid e Flexbox:** Organização dinâmica e adaptativa de múltiplos estilos de cartões numa grelha responsiva.
* **Posicionamento Avançado (`position`):** Gestão de elementos flutuantes, alinhamento de avatares e estruturação de cartões com destaque visual.
* **Componentes Modulares:** Estilização isolada para diferentes variações de depoimentos (balões de fala escuros, cartões clássicos, cartões de classificação por estrelas e navegação interativa).
* **Design Responsivo:** Aplicação de *media queries* para assegurar uma visualização fluida em dispositivos móveis e ecrãs de secretária.

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**
* **CSS3** (Grid, Flexbox, Variáveis CSS, Posicionamento)
* **Git & GitHub** para controlo de versões
